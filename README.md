A GitHub-compatible git forge in a single Node.js process: git smart HTTP (protocol v0 and v2, fetch/clone/push with shallow clones and sideband packs), the GitHub REST v3 API (repositories, branches, commits, contents, issues, labels, comments and pull requests with squash merge), a GraphQL API (viewer, repository, issues, pull requests, node, introspection and mutations), and an MCP server (six tools) — all backed by one in-memory store, no database, no model calls.

## Run it

```sh
node main.ts
```
